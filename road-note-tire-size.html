Tire Buying Guide

How to Read the Tire Size on the Sidewall

A tire-size string is a starting point for a Tire Availability request. Use the size shown on the tire or send the vehicle year, make and model if you are unsure.

TIRE SIDEWALL / SIZE CODE

START WITH THE SIDEWALL

Most passenger tires show a size code on the sidewall. Use that code exactly as written when you send a tire request. If the tire is damaged or the marking is hard to read, include the vehicle year, make and model so the shop has another way to start the fitment conversation.

SIZE DOES NOT CONFIRM INVENTORY

A size tells the shop what you are looking for; it does not mean a New or Used Tire is automatically available. Tires 4 Less confirms the actual option, quantity and location after the request.

WHEN TO ASK THE SHOP

If you are unsure whether the tire currently on the vehicle is the correct fit, do not guess from a nearby size. Send the vehicle information and let the shop confirm the appropriate next step.
